# Security policy

## Scope

Graphlore is a personal, pre-release project with no published releases and no support
commitment. See [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) for what it does and does not defend
against.

## Reporting a vulnerability

Please report problems privately through GitHub:
**Security tab > Report a vulnerability** on this repository (private vulnerability reporting).
Do not open a public issue for a security problem.

Include the affected version or commit, steps to reproduce, and the impact you expect. Reports are
read on a best-effort basis; there is no guaranteed response time.

## Please do not

- Send real credentials, personal data or proprietary documents in a report.
- Test against systems you do not own.
