## [0.1.0]

### Added

- YAML ontology with typed relations, trigger phrases, question cues, symmetric and inverse
  relations, and consistency checks.
- Sentence-aware chunker, document loader, and rule, spaCy and model-based extractors.
- Entity resolution with documented merge and review thresholds.
- Graph store interface with NetworkX and Neo4j implementations; mandatory provenance.
- Bounded multi-hop retrieval with cited, deterministic answers and abstention.
- Evaluation harness, JSON and GraphML export, and a command line interface.
- Hand-written fictional sample corpus, gazetteer and question set.
